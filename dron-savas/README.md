# Dron Savaşı

Mobil (Android) için koloni ve modern savaş simülasyonu: prosedürel kıta, birbirine bağlı altyapı ağları, dronlar, füzeler, hava savunması, elektronik harp ve en fazla 8 (deneysel 24) yapay zekâlı ülke.

- **Kurulum:** `release/DronSavasi.apk` dosyasını telefona kopyalayıp açın ("bilinmeyen kaynaklar" izni gerekir).
- **Geliştirme:** `npm install && node build.mjs && bash tools/build-apk.sh`
- **Test:** `node tests/run-all.mjs`

Ayrıntılar için `ARCHITECTURE.md`, `PROGRESS.md`, `CHANGELOG.md` ve `CREDITS.md` dosyalarına bakın.
